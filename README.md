# 🤖 Machine Learning Projects

A collection of machine learning projects focused on solving real-world classification problems using Python and Scikit-learn/XGBoost.

## 📂 Projects

### 1. 💳 Credit Card Fraud Detection

A binary classification project that detects fraudulent credit card transactions using **XGBoost Classifier**.

**Key Concepts:**

* Data preprocessing
* Class imbalance
* XGBoost
* Train-test split
* Precision, Recall & F1-Score
* ROC-AUC & Precision-Recall
* Confusion Matrix

📁 `credit_card_fraud.ipynb`

---

### 2. 🏥 Hospital Readmission Prediction

A classification project that predicts hospital readmission using patient and hospital-related data with **Logistic Regression**.

**Key Concepts:**

* Data preprocessing
* Missing value handling
* Categorical encoding
* Feature scaling
* Logistic Regression
* Classification metrics
* Confusion Matrix & ROC-AUC

📁 `hospital_readmission.ipynb`
